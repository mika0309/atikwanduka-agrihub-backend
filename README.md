# Atikwanduka AgriHub

A government-aligned digital agriculture platform designed to improve market access, subsidy transparency, and financial inclusion for smallholder farmers in Tanzania.

## Features
- Farmer registration and login
- JWT authentication
- Role-based authorization
- Production record management
- Credit scoring engine
- Subsidy voucher management

## Tech Stack
- Node.js
- Express.js
- PostgreSQL
- JWT
- bcrypt
